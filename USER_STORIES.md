# Offertrail — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Loyalty / CX lead

- As a loyalty lead, I want to design an offer that trades a birthday for a birthday reward, so that the ask is purpose-limited and commercially meaningful.
- As a loyalty lead, I want to compare fulfilment rates across acquire versus win-back journeys, so that I retire offers that collect data without delivering value.
- As a loyalty lead, I want to pause all third-party-share offers during a trust incident, so that we do not compound consumer backlash.

### Privacy counsel

- As privacy counsel, I want to reject an offer that requests more data categories than the stated purpose needs, so that minimisation is enforced before launch.
- As privacy counsel, I want an auditable approval trail for each live offer, so that I can evidence accountability to regulators and the board.

### Journey owner / merchandiser

- As a journey owner, I want template packs for “better service” and “choosable third-party share” offers, so that I am not inventing consent copy from scratch.
- As a merchandiser, I want proof that a promised discount was issued when consent was granted, so that marketing claims match fulfilment.

### Consumer support agent

- As a support agent, I want to look up which offers a customer accepted and revoke one on their behalf, so that trust failures do not require a legal ticket for every routine ask.

### Platform administrator

- As a platform administrator, I want to limit which teams can publish offers that include third-party sharing, so that high-risk monetisation cannot bypass the DPO gate.
- As a platform administrator, I want negative-path handling when fulfilment systems fail after consent, so that we automatically freeze further collection for that offer until repaired.
